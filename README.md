🐍 Atividade Prática – Python

Repositório desenvolvido para a atividade prática da disciplina de Python, com o objetivo de aplicar e aprimorar conceitos fundamentais de lógica de programação e desenvolvimento de algoritmos.

O projeto é composto por 6 desafios independentes, cada um desenvolvido em um arquivo .py, trabalhando diferentes conceitos da linguagem Python.

🎯 Objetivo

Desenvolver a capacidade de resolver problemas utilizando:

Variáveis e tipos de dados;

Operadores e expressões;

Estruturas condicionais (if, elif, else);

Estruturas de repetição (for e while);

Listas;

Funções;

Manipulação básica de dados;

Entrada e saída de informações;

Cálculos e análises de dados.

📝 Desafios desenvolvidos


1️⃣ Classificador de desempenho acadêmico

Programa responsável por receber o nome do aluno, três notas e a quantidade de faltas.

O sistema calcula a média e determina a situação do aluno de acordo com os critérios estabelecidos:

Aprovado: média ≥ 7 e faltas ≤ 10;

Recuperação: média entre 5 e 6,9;

Reprovado: média < 5;

Reprovado por falta: mais de 10 faltas.

Ao final, são exibidos o nome, a média e a situação do aluno.

Conceitos utilizados: variáveis, entrada de dados, operadores, condicionais e cálculos.

2️⃣ Analisador de consumo mensal

Programa que recebe o consumo de energia elétrica de uma residência durante 6 meses e armazena os valores em uma lista.

O sistema realiza uma análise dos dados, apresentando:

Consumo médio;

Maior consumo;

Menor consumo;

Quantidade de meses acima da média;

Posição do mês com maior consumo.

Conceitos utilizados: listas, estruturas de repetição, funções de agregação e análise de dados.

3️⃣ Sistema de autenticação simples

Sistema básico de login utilizando um usuário e uma senha previamente definidos no código.

O usuário possui no máximo 3 tentativas para realizar a autenticação.

O programa:

Verifica usuário e senha;

Informa quando os dados estão incorretos;

Libera o acesso quando as credenciais estão corretas;

Bloqueia o acesso após três tentativas incorretas.

O desafio foi desenvolvido utilizando apenas recursos nativos do Python, sem bibliotecas externas.

Conceitos utilizados: condicionais, estruturas de repetição, variáveis e controle de tentativas.

4️⃣ Cadastro e análise de produtos

Programa para cadastrar 5 produtos, armazenando:

Nome;

Preço;

Quantidade em estoque.

Após o cadastro, o sistema realiza uma análise dos produtos e informa:

Produto mais caro;

Produto mais barato;

Valor total do estoque de cada produto;

Valor total de todo o estoque.


O valor do estoque é calculado através da fórmula:

Valor do estoque = Preço × Quantidade

Conceitos utilizados: listas, estruturas de repetição, condicionais, cálculos e manipulação de dados.

5️⃣ Função para análise de senhas

Desenvolvimento da função validar_senha(), responsável por analisar a segurança de uma senha.

A senha é considerada Forte quando possui:

Pelo menos 8 caracteres

Pelo menos uma letra

Pelo menos um número

Pelo menos um caractere especial.

Caso a senha não atenda aos requisitos, o programa informa quais critérios não foram cumpridos.

Conceitos utilizados: funções, strings, condicionais, operadores e validação de dados.

6️⃣ Mini sistema de análise de dados

Programa desenvolvido para analisar as notas de 10 alunos.

O sistema calcula:

Média da turma;

Maior nota;

Menor nota;

Quantidade de alunos aprovados;

Quantidade de alunos em recuperação;

Quantidade de alunos reprovados.

Critérios utilizados:

Situação	Nota

✅ Aprovado	Nota ≥ 7

🟡 Recuperação	Nota ≥ 5 e < 7

❌ Reprovado	Nota < 5

Ao final, é apresentado um pequeno relatório contendo a média geral, maior e menor nota e o total de alunos em cada situação.

Conceitos utilizados: listas, estruturas de repetição, condicionais, cálculos, contadores e análise de dados.
